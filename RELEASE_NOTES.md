# Dinox Desktop 4.3.0

## Что нового

- **Минималистичный остров:** обзор, календарь, музыка и управление после раскрытия. Время остаётся на месте; закреплённые CPU и батарея не дублируются. Выбор профиля убран в раскрываемый пункт.
- **Док:** необязательное мягкое увеличение значков без сдвига их центров и перекрытий. Выключено по умолчанию; отключается при переносе файлов, экономии ресурсов и уменьшении движения. Улучшены перестановка закреплений, группировка окон и выбор окна в превью.
- **Перенос файлов через скрывающийся док:** док удерживается открытым, наведение на работающее приложение или превью выбирает нужное окно без его сворачивания. Отпускать файл нужно в самом окне назначения. Док не принимает файлы и не запускает закрытые приложения.
- **Быстрые настройки:** собственные панели Wi-Fi, Bluetooth, аудиоустройств, микрофона, микшера и питания. Изменения подтверждаются чтением состояния Windows; ошибки видны в интерфейсе. Дополнительные переходы в Windows спрятаны.
- **Календарь:** выбор видимых календарей без длинного списка над сеткой, цвета источников, улучшенные события на весь день и компактное создание записей.
- **Уведомления:** высота по содержимому, исправление отметки прочтения при закрытии истории, режим «Не беспокоить» Dinox и настройки приватности.
- **Лимиты ИИ — опционально:** Codex и Claude Code, пятичасовые и недельные окна при наличии в источнике. Недоступные и устаревшие данные явно отличаются от актуальных.
- **Единое оформление:** светлая/тёмная палитры, контраст, клавиатурный фокус, узкие экраны и размещение панелей. Усилены сохранение подтверждённых настроек и восстановление панели Windows.

## Установка и обновление

Скачайте **Dinox-Desktop_4.3.0_x64-setup.exe**. В установленном Dinox: **Настройки → О программе → Проверить обновления**. Автоустановка при следующем запуске включается отдельно.

Сохранены идентификатор приложения и хранилища настроек, календарей и подключений. Релиз не сбрасывает их и не устанавливает разрешения или сертификаты автоматически. Перед выходом для обновления приложение восстанавливает рабочую область Windows.

Файлы автообновления защищены подписью канала Dinox. Это **не Authenticode-подпись издателя Windows**; Windows может показать предупреждение о неизвестном издателе. Основная платформа — Windows 11 x64.

## Ограничения

- Реальный перенос файлов через док и изменения аудиоустройств/питания из установленной новой версии ещё не подтверждены сквозным тестом на оборудовании. Браузерные проверки используют искусственные данные.
- Codex требует официальный CLI; это лимиты Codex, а не всех моделей чата ChatGPT. Claude Code передаёт лимиты через локальный statusLine после ответа модели. Источник может устаревать. Подключение выполняется отдельным действием пользователя.
- Google — непроверенный бесплатный пилот до 100 пользователей с предупреждением Google. Google Tasks поддерживает срок по дате, но не точное время. Редактирование и удаление событий Google через Dinox не добавлены.
- Яндекс и другие ICS — только чтение; задачи видны при наличии в экспорте. Создание записей в Яндексе не включено в публичный интерфейс.
- Уведомления других программ требуют идентификации пакета и разрешения Windows. Собственные всплывающие окна Telegram не читаются; фото контакта доступно не всегда.
- Экспериментальный Telegram-транспорт выключен по умолчанию. Доступность зависит от сети; звонки и медиа не гарантированы.
- Совместимость со всеми драйверами/дисплеями и представительные замеры батареи пока не подтверждены. **Ctrl+Alt+B** возвращает панель Windows.

## Проверки

126 модульных тестов, TypeScript, production-сборка интерфейса и проверка компиляции Rust. Для изменений интерфейса выполнены 208 браузерных проверок: навигация, размещение, уведомления, док, искусственный перенос файлов, клавиатура и уменьшение движения. Установщик и файлы автообновления собираются и подписываются в GitHub Actions.

## English

Refined minimalist island and dock, optional bounded icon magnification, a file-drag window activation bridge, native quick controls, calendar visibility, notification sizing/read tracking, and optional Codex/Claude Code usage indicators. Existing application identity and settings stores are retained. Browser fixtures do not establish real Windows file-transfer or hardware-control compatibility. Google remains an unverified 100-user pilot; ICS is read-only. Updater signatures are separate from Windows Authenticode signing.
