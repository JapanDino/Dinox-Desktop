Privacy policy

Effective September 28, 2026. Publisher: JapanDino, maintainer of Dinox Desktop.

Кратко: Dinox работает на вашем компьютере. Подключение Google добровольное; запросы идут напрямую в Google, токены и кэш аккаунтов защищены средствами Windows. Мы не получаем ваши календари на собственный сервер, не продаём их и не используем для рекламы или обучения ИИ. Отключение аккаунта удаляет его данные из активного хранилища Dinox, но не исходные записи в Google. Ниже приведена полная политика.

What this policy covers

This policy covers the Dinox Desktop application, its optional calendar integrations and this project website. Features differ between releases. The Google integration is an unverified public pilot with a 100-user cap; this page does not claim Google verification or universal availability.

Optional Google access

When you choose Connect Google, Google handles sign-in in a browser and asks you to authorize access. Dinox does not receive your Google password. It uses these permissions:

PermissionPurpose in Dinox
Calendar list (read-only)Discover your calendars and their access roles so you can choose where to display and create events.
Calendar eventsRead event titles, dates, times, descriptions and links for the calendar views; create events in a writable calendar when you ask. The scope permits broader event changes, but the current interface does not offer event editing or deletion.
Google TasksRead task lists, titles, notes, due dates and completion state; create tasks and mark them complete or incomplete when you ask.

Dinox also uses the primary calendar identifier and name as the connected account label. Google requests are sent directly from your computer to Google. There is no Dinox-hosted calendar relay or calendar database.

Storage and retention

OAuth access and refresh tokens, connected account metadata, cached events/tasks and the creation-operation journal are stored locally in a Windows DPAPI-protected account file. A local cache supports offline display. Google calendar refresh currently requests approximately one year of past events and two years of future events; tasks include completed and undated tasks.

Disconnecting an account in Dinox removes its tokens, cached collections and creation journal from the active account store. It does not delete events or tasks at Google and does not revoke the consent recorded in your Google account. To revoke that access, remove Dinox Desktop from Google Account connections. Backups, filesystem recovery data or copies you exported may persist outside Dinox's active store; deletion is not a secure disk erase.

Private ICS subscription links and downloaded feed content are stored locally using Windows protection. Treat these links as secrets: anyone with a valid private link may be able to read the feed. Remove a subscription in Dinox to remove it from the active subscription store; revoke or regenerate its link at the calendar provider if it has been exposed.

Other local features and network requests

  • Notes, widget content and preferences are stored locally. They are not all encrypted with DPAPI; anyone able to access your Windows profile or its backups may be able to read them.
  • With your permission, the optional Windows notification feature reads notifications exposed by Windows to display local cards. Notification content is held in application memory rather than sent to a Dinox server. Available sender names and images depend on the originating app.
  • App/file search uses local Windows data. Choosing a web-search result opens your chosen search provider with the query; that provider receives it.
  • Enabled weather features contact Open-Meteo with coordinates. Automatic location lookup can contact ipapi.co or ip-api.com using your network address. These providers receive connection metadata.
  • Update checks and downloads contact GitHub. ICS refresh contacts the provider of the link you entered. These services receive normal network metadata such as your IP address.
  • This static website uses no project-added analytics, advertising scripts, cookies or external fonts. GitHub Pages, as the host, may process request metadata under GitHub's privacy statement.

Optional Telegram transport

The experimental Telegram transport is off by default. When enabled, a bundled local process listens only on 127.0.0.1 and forwards Telegram traffic to Telegram endpoints. There is no Dinox relay or Cloudflare Worker. Its connection secret is stored with Windows DPAPI protection; the transport does not write message or traffic logs. Enabling it does not change Windows networking. You choose separately whether Telegram uses this local proxy; exiting Dinox stops the transport.

Use and sharing of Google data

Google data is used only for the user-facing calendar and task features described above. The publisher does not sell this data, use it for advertising, transfer it to data brokers, use it to train generalized AI models or receive it for routine human review. No analytics or advertising service receives Google calendar/task data from Dinox. The application sends data to Google when necessary to perform the actions you request.

Dinox Desktop's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Your choices and contact

You can use local desktop features without connecting Google, use read-only ICS instead, disconnect accounts, remove subscriptions and revoke Google access. Uninstalling may leave local preferences or WebView data; uninstalling alone is not a request to erase all local data.

For privacy questions or help locating local data, contact klim.i.rumyantsev@gmail.com. Do not put tokens, private calendar links, event contents or personal notifications in public issue reports. Information you voluntarily send in support messages is used to respond to your request.

Changes

Changes to this policy will be published here with an updated effective date. New integrations that need additional permissions will require the corresponding authorization.
