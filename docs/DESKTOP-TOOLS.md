# Поиск, микшер и редактор рабочего стола

Эти функции реализованы в исходниках Dinox. Установленная версия автоматически не меняется.

## Поиск в стиле Spotlight / PowerToys Run

- **Alt + Space** открывает и скрывает отдельное окно поиска. **Esc** и потеря фокуса закрывают его. Повторное открытие начинает новый поиск.
- **↑ / ↓** выбирают результат, **Enter** открывает его. Поддерживается ввод с IME.
- Источники: установленные приложения, имена файлов из индекса Windows Search, команды Dinox и интернет.
- Короткие команды ограничивают область поиска. Google, Яндекс и Bing выбираются в меню настройки поиска; запрос в интернет отправляется только при открытии результата, через браузер по умолчанию.
- В **Настройки → Основные → Поиск Dinox → Горячая клавиша поиска** Alt + Space можно заменить на Ctrl + Alt + Space или отключить. Изменения применяются сразу и синхронизируются с меню самого поиска. Если регистрация сочетания не удалась, интерфейс показывает конфликт. Кнопка поиска в доке остаётся доступной. Включённый Alt + Space заменяет обычное системное меню окна для этого сочетания.
- Кнопку поиска можно скрыть в **Настройки → Рабочий стол → Док**.

### Собственное сочетание и конфликты

В **Основные → Поиск Dinox** нажмите **Задать своё сочетание…**, нажмите клавиши и выберите **Сохранить**. Поддерживаются Ctrl и/или Alt, необязательный Shift и буква, цифра, пробел, функциональная или навигационная клавиша. Буквы записываются по физической клавише и сохраняют привязку при смене раскладки. Win, F12, системные Alt+Tab/Alt+F4/Ctrl+Alt+Delete и аварийный Ctrl+Alt+B не назначаются. Esc отменяет запись.

Во время записи Dinox временно освобождает собственный хоткей. При отмене, уходе из раздела или потере фокуса он восстанавливается; нативный тайм-аут 60 секунд страхует случай закрытия интерфейса. Другие приложения при записи могут перехватывать свои сочетания — освободите конфликтующий хоткей в их настройках или выберите другой.

Проверка Windows выполняется при запуске и каждом изменении сочетания. При отказе регистрации Dinox показывает подсказку и кнопку **Подключить повторно**. Для Alt+Space приведены инструкции по PowerToys Run и Copilot. PowerToys обычно использует Alt+Space: переназначьте его запуск, например на Alt+Shift+Space, затем повторите подключение в Dinox. Чужие настройки приложение автоматически не изменяет. Проверка RegisterHotKey выявляет отказы регистрации, но не определяет владельца и не гарантирует отсутствие сторонних низкоуровневых перехватчиков клавиатуры.

Поиск файлов начинается с двух символов, после паузы 320 мс. Возвращается до 25 локальных файлов; сетевые UNC-адреса исключены. Поиск по содержимому документов и папки вне индекса Windows пока не поддерживаются. Доступность файлов зависит от службы Windows Search и настроенного индекса.

Окно создаётся при первом вызове. Dinox не создаёт собственный индекс диска. Для запросов используется Windows Search SQL через отдельный скрытый процесс PowerShell: пользовательский ввод передаётся через переменную окружения, одинарные кавычки экранируются для SQL. Запросы сериализуются, устаревшие отменяются, тайм-аут составляет 5 секунд. Это ограничивает фоновую работу, но не является измерением CPU, RAM или батареи.

Пустая строка показывает подсказки, как в командной панели PowerToys:

| Ввод | Действие |
| --- | --- |
| `= (5 * 3) - 2` | Вычислить; Enter копирует `13` |
| `? проект` | Файлы и папки из индекса Windows |
| `. Telegram` | Установленные приложения |
| `@` | Команды Dinox |
| `!!` | Недавно открытые приложения, файлы и команды |
| `> запрос` | Интернет через выбранный поисковик |
| `g запрос`, `y запрос`, `b запрос` | Google, Яндекс, Bing соответственно |

Префиксы необязательны: обычный текст ищет сразу в приложениях, файлах и командах и предлагает интернет-результат. Калькулятор использует собственный ограниченный арифметический парсер, без `eval` и запуска команд. Поддерживает скобки, десятичную запятую/точку, + − × ÷, остаток `%`, степень `^`, унарные знаки. Результат округляется до 14 значащих цифр; деление на ноль и слишком большие выражения показывают ошибку.

История хранится в `sessionStorage` окна поиска и очищается при завершении его сеанса. В меню настройки поиска есть «Очистить историю». Интернет-запросы и вычисления в историю не попадают. Копирование результата использует Clipboard API WebView2 и показывает ошибку при отказе; в браузерных тестах подставляется отдельный имитатор буфера, системный буфер пользователя не меняется.

## Микшер

**Док → Быстрые настройки → Микшер приложений** открывает панель Dinox.

- Выбор устройства для просмотра его аудиосессий.
- Общая громкость устройства и отдельные громкость / mute для каждого приложения.
- Кнопка «Использовать по умолчанию» меняет основной выход Windows. Простое выделение устройства в списке ничего не переключает.
- После изменения интерфейс повторно читает состояние Windows. Ошибка сохраняет панель открытой; неудачное изменение громкости откатывается к прочитанному состоянию.
- Список обновляется раз в 3 секунды только пока панель смонтирована и страница видима. Постоянных анимированных индикаторов уровня нет.

Аудиосессии реализованы через Windows Core Audio. Переключение основного выхода использует изолированный интерфейс совместимости `IPolicyConfig`: у Windows нет соответствующего общедоступного setter в MMDevice API. Выход для звонков не меняется. Если одна из двух ролей не переключается, код пытается вернуть уже изменённую роль. Приложения с собственным выбором выхода могут остаться на прежнем устройстве.

**Пока нет:** перенаправления отдельного приложения на другое устройство, управления входами / усилением микрофона, пиковых индикаторов. Это не полный клон EarTrumpet.

## Редактор рабочего стола

**Настройки → Рабочий стол** объединяет остров и док в одном предпросмотре.

- Выбор панели нажатием на неё или вкладкой.
- Дата, CPU и заряд рядом со временем, режим появления острова.
- Перестановка виджетов раскрытого острова; максимум два на каждой стороне.
- Размер, расстояние, скругление и положение дока, его видимость, поведение и кнопка поиска.
- **Сохранить** применяет изменённые поля одним атомарным обновлением; **Отменить** возвращает исходный предпросмотр.
- Если те же поля успели измениться в другом окне, сохранение отклоняется с предложением загрузить актуальные настройки. Несвязанные настройки не перезаписываются.

Показатели и приложения на рисунке рабочего стола демонстрационные. Режимы появления сохраняются, но рисунок не симулирует перекрытие реальными окнами.

Позже локальная нативная сборка была запущена и открытие поиска по Alt+Space проверено после согласованного пользователем переназначения PowerToys Run. Для других компьютеров добавлены настройка своего сочетания, сообщение о конфликте и повторная регистрация; чужие настройки Dinox не меняет. Репрезентативная проверка разных мониторов, масштабов и аудиоустройств остаётся отдельной задачей. Актуальные проверки релизов перечислены в [VALIDATION.md](VALIDATION.md).

Сбои: `&copy-error`, `&search-error`, `&open-error`, `&shortcut-conflict`, `&mixer-error`, `&mixer-write-error`, `&mixer-empty`, `&save-error`, `&layout-conflict`.
