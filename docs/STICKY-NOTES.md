# Заметки Dinox

Реализовано 26–28 сентября 2026 в исходниках и браузерном демо. Нативная установка этим изменением не обновлялась.

## Сценарии

Виджеты → Заметки → «Все заметки» / «Новая заметка». Библиотека содержит поиск по заголовку, тексту и ссылке, шесть цветов, фильтр по цвету и закрепление. Список показывает первые 60 записей; остальные доступны по «Показать ещё».

Редактор: заголовок, жирный, курсив, подчёркивание, зачёркивание, маркированные списки, отмена/повтор, изображения из файла, вставки или перетаскивания, ссылка на источник. Ctrl+N создаёт заметку, Ctrl+F переводит к поиску. Esc закрывает библиотеку; на узком экране сначала возвращает к списку.

Удаление перемещает заметку в корзину. Есть отмена, восстановление, выбор нескольких заметок и окончательное удаление с подтверждением. Выбор всех относится ко всем результатам текущего фильтра, включая ещё не показанные карточки.

Кнопка отдельного окна вызывает нативный обработчик `notes_open_window`: обычное перемещаемое окно 440×560, изменение размеров, отдельное закрепление поверх окон. Максимум 12 открытых окон. Они не резервируют место рабочего стола. Закрытие ожидает сохранения. Окно открытой заметки не закрывается из-за потери фокуса.

## Данные

- IndexedDB `dinox-sticky-notes`: отдельные записи, автоматическое сохранение и проверка ревизии при записи. BroadcastChannel обновляет другие окна.
- Прежняя строка `dinox-widget-note-data` переносится один раз в `legacy-v1`, исходная запись остаётся.
- До записи создаётся аварийный черновик в localStorage. При отказе обоих хранилищ сохранность после завершения процесса не гарантируется; интерфейс показывает ошибку и запрещает закрытие библиотеки с несохранёнными изменениями.
- Конкурирующая запись не перезаписывает более новую ревизию. Пользователь может сохранить свой вариант отдельной копией.
- Резервная копия JSON включает корзину. В Windows место сохранения выбирается системным диалогом; в демо используется загрузка браузера. Импорт копии через интерфейс пока не реализован.
- До 100 000 символов и 8 изображений в заметке. PNG/JPEG/WebP до 10 МБ при добавлении уменьшаются до 1400 px и сохраняются локально как JPEG. Удалённые картинки и активный HTML не сохраняются как исполняемый контент.
- Нет аккаунта OneNote, облачной синхронизации, OCR и автоматического захвата текущего окна. Это самостоятельные локальные заметки Dinox с основными сценариями Sticky Notes.

## Проверка

- 68 Bun-тестов, 1 178 assertions, без ошибок.
- `sticky-notes.browser.mjs`: 20 проверок миграции, форматирования, изображений, сохранения, отдельного окна в демо, поиска, корзины и адаптивности 1440 / 800 / 390 px.
- `sticky-notes-reliability.browser.mjs`: 10 проверок отказа записи, сохранения черновика, конфликта ревизий, библиотеки из 80 заметок и массового удаления.
- `sticky-notes-windows.browser.mjs`: 3 проверки двух независимых браузерных страниц и восстановления после прерванной записи.
- Регрессия соседних личных виджетов: 23 проверки. Старые проверки однострочной заметки заменены отдельными наборами выше.
- Production-сборка TypeScript/Vite и `cargo check --release --locked --offline` прошли. Нативные окна, Z-порядок, системный диалог и вставка из буфера Windows в установленном приложении пока не проверены.
