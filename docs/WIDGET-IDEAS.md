# Дальнейшее развитие панели виджетов

План развития, 26 сентября 2026. В рабочей копии уже реализованы задачи со сроками, заметка, подборка проектов, музыка, размеры и порядок карточек. Они проверены в демо; локальная 4.1.1 ещё содержит прежние три виджета. Ниже сохранены дальнейшие идеи, включая синхронизацию, экспорт, ближайшее событие, погоду и показатели компьютера.

## Первыми добавить

1. **Задачи на сегодня.** Быстро добавить строку, отметить выполнение, перенести на завтра. Сначала локальное хранение; синхронизацию с сервисами задач подключать отдельно. Не превращать события ICS в редактируемые задачи.
2. **Быстрая заметка.** Записать мысль без открытия редактора; автосохранение локально с видимым состоянием сохранения и восстановлением после ошибки. Позже — явный экспорт в Markdown, включая выбранную папку Obsidian.
3. **Следующее событие.** Крупное название, время до начала, место или кнопка присоединения по ссылке из события. Брать данные из общего календаря Google / Яндекс / ICS, не запускать отдельную синхронизацию. Когда встречи пересекаются — показывать это; если ближайшая уже идёт — показывать время до конца. Для событий на весь день не нужен секундный отсчёт.

## Дополнительные карточки

| Карточка | Что пользователь делает | Особенности |
| --- | --- | --- |
| Музыка | Пауза, следующий трек, обложка | Использовать текущую системную медиасессию; ясное пустое состояние, если плеер не поддерживается. |
| Погода | Видит ближайшие часы и вероятность дождя | Общий кеш существующего погодного модуля; выбранный город вместо новой геолокации. |
| Компьютер | Видит CPU, RAM, заряд и режим питания | Подписка на существующие показатели. GPU только если доступен реальный источник, без подмены RAM. Обновления нужны лишь при открытой панели. |
| Избранное | Открывает закреплённые проекты, папки, программы и ссылки | Собственная подборка для виджетов, без изменения закреплений Windows. Редактор с понятными названиями и иконками. |
| Обратный отсчёт | Видит, сколько осталось до экзамена, поездки или дедлайна | Дни и часы, а не постоянно обновляющиеся секунды. Часовой пояс и конечная дата видимы. |

Не включать чтение буфера обмена и превью личных сообщений по умолчанию. Такие карточки нуждаются в отдельном включении и способе быстро скрыть содержимое перед демонстрацией экрана.

## Организация и нагрузка

- По умолчанию 3–4 карточки: календарь — широкая, задачи и фокус — компактные. Остальные пользователь добавляет сам.
- Следующий этап настройки: размеры S/M/L, перестановка карточек, скрытие. Редактирование включается отдельной кнопкой; случайное перетаскивание во время обычных кликов исключается. Для клавиатуры нужны команды перемещения без drag-and-drop.
- На узком экране — одна колонка с доступной шапкой и закрытием; недельный календарь сохраняет свою горизонтальную прокрутку.
- При скрытии панели прекращать обновления интерфейса; общий кеш и системные события предпочтительнее отдельного опроса для каждой карточки.
- Не оценивать батарею выдуманными процентами: сравнивать измерения приложения с закрытой и открытой панелью на конкретном компьютере.
